## 关键决策记录

| 决策 | 背景 | 选择 | 原因 |
| ---- | ---- | ---- | ---- |
| 使用 Next.js Image 组件 | Logo 需要响应式和优化 | ✅ 采用 | 自动优化、支持多种尺寸 |
| 静态导出模式 | GitHub Pages 仅支持静态内容 | ✅ output: 'export' | 兼容性最佳 |
| CI/CD 平台选择 | 已有 GitHub 仓库 | ✅ GitHub Actions | 免费且深度集成 |
| API 路由处理策略 | 静态导出不支持 Server Functions | ⏳ 延迟决策 | 需确认用户需求 |
| 保持 ignoreBuildErrors | 当前 TS 错误较多 | ⚠️ 临时保留 | 避免阻塞当前部署 |
