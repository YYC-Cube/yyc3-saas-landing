**Next.js 与 GitHub Pages 兼容性**：

⚠️ **重要技术约束**：

- GitHub Pages 仅支持**静态输出**（Static Export）
- Next.js 默认需要 Node.js server-side rendering
- 必须配置 `output: 'export'` in next.config.mjs
- API 路由（app/api/**）在静态导出时**不可用**

#### 解决方案

**步骤 1：配置 next.config.mjs 启用静态导出**

```javascript
// next.config.mjs
const nextConfig = {
  output: 'export',  // ← 添加这行
  // ... 其他配置
}
```

**步骤 2：创建 CNAME 文件**

```bash
echo "saas.yyc3.vip" > public/CNAME
```

**步骤 3：创建 GitHub Actions 工作流**（详见 5.3 节）

**步骤 4：处理 API 路由兼容性**

由于 GitHub Pages 不支持服务端 API，有以下选择：

- **选项 A**：将 AI API 部署到独立服务（如 Vercel Serverless Functions）
- **选项 B**：使用客户端直接调用外部 API（需处理 CORS）
- **选项 C**：仅将 Landing Page 部署到 Pages，API 部署到其他平台

**DNS 配置验证清单**：

- [ ] A 记录或 CNAME 指向 GitHub Pages IP (`185.199.108.153` 等)
- [ ] WWW 子域名重定向配置（可选）
- [ ] HTTPS 证书自动签发（GitHub Pages 自动提供 Let's Encrypt）
- [ ] DNS TTL 设置合理（建议 3600s 或更低以便快速生效）

**架构设计**：

```
┌─────────────────────────────────────────────────────────────┐
│                  CI/CD Pipeline Architecture                │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Trigger: Push to main / Pull Request / Manual               │
│                         ↓                                     │
│  ┌──────────────────────────────────────────────┐           │
│  │         Stage 1: Code Quality (CI)            │           │
│  │  ├─ Lint Check (eslint)                      │           │
│  │  ├─ Type Check (tsc --noEmit)                │           │
│  │  └─ Unit Tests (jest/vitest) [待添加]        │           │
│  └──────────────────────┬───────────────────────┘           │
│                         ↓ Pass                                │
│  ┌──────────────────────────────────────────────┐           │
│  │       Stage 2: Build (Compile)                │           │
│  │  ├─ pnpm install                            │           │
│  │  ├─ pnpm build (next build)                 │           │
│  │  └─ Output: ./out/ (static files)            │           │
│  └──────────────────────┬───────────────────────┘           │
│                         ↓ Success                              │
│  ┌──────────────────────────────────────────────┐           │
│  │      Stage 3: Deploy (CD)                     │           │
│  │  ├─ Deploy to GitHub Pages (main branch)     │           │
│  │  └─ Preview: GitHub Preview Environment      │           │
│  └──────────────────────────────────────────────┘           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**工作流文件：`.github/workflows/deploy.yml`**

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm lint

      - name: Type check
        run: pnpm tsc --noEmit || true  # 暂时允许失败

      - name: Build
        run: pnpm build

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./out

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

**额外推荐的 CI 工作流**：

1. **`.github/workflows/ci.yml`** - PR 质量检查（不部署）
2. **`.github/dependabot.yml`** - 自动依赖更新
3. **`.github/codeql.yml`** - 安全扫描（可选）
